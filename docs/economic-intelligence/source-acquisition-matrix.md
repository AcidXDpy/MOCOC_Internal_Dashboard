# Source Acquisition Matrix

Design and source review: 2026-09-07. Companion to [the technical design](technical-design.md), section 2. Links below are acquisition or primary documentation locations checked for this design; a working catalog is not proof that a complete local history is downloadable. Metadata inspection is not panel acquisition. Years in examples are pinned examples, not claims about the latest release.

## Evidence Status

| Status                               | Meaning in these documents                                                                                                                                                                             |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Existing directory/context           | 116 public directory listings dated 2026-07-16 and original ACS/CBP/ZBP context. Directory lifecycle fields are not longitudinal business outcomes.                                                    |
| Acquired during parallel integration | Observed caches/results: Morris County LAUS January 2000-July 2026, ACS 2024 Morris tract data/boundaries, and NJ county CBP 2018-2023. These are real acquired inputs with their own coverage limits. |
| Public acquisition candidate         | Official source or metadata located. Full history, local coverage, releases, permissions, and joins still require an ingestion audit.                                                                  |
| Requested data                       | A proposed field specification for a partner or records request. No delivery, access agreement, or existing API is claimed.                                                                            |
| Derived                              | A transformation of acquired observations, with inputs and uncertainty preserved.                                                                                                                      |
| Model output                         | An estimate or simulation conditional on data and assumptions, never stored as an observation.                                                                                                         |

The parallel implementation acquired the county/tract inputs listed above while these documents were prepared. This documentation work verified source metadata and inspected the resulting caches/contracts; it did not perform those panel downloads. In the matrix, S02/S03/S12 have acquired Morris-tract subsets, S04 acquired Morris monthly employment/unemployment-rate history, and S06 acquired NJ county comparisons. Wider histories, other counties for LAUS, QCEW, LODES, local event/sensor/cohort data and other sources remain acquisition candidates unless later confirmed. Costs describe access, not engineering, storage or records-processing effort. Revalidate terms and metadata when implementing.

## Acquisition Contracts and Examples

The following are request templates, not executed panel downloads. Validate `variables.json`, geography metadata, filters, and returned names before scheduling. Pin each dataset year separately.

```text
ACS tract context:
https://api.census.gov/data/2024/acs/acs5?get=NAME,B01003_001E,B01003_001M,B23025_004E,B23025_004M&for=tract:*&in=state:34%20county:027

CBP Morris County, all sectors, all sizes/legal forms:
https://api.census.gov/data/2023/cbp?get=NAME,ESTAB,EMP,PAYANN&for=county:027&in=state:34&NAICS2017=00&LFO=001&EMPSZES=001

QCEW by-area quarterly file pattern:
https://data.bls.gov/cew/data/api/{year}/{quarter}/area/34027.csv

NJ permit schema before any paginated extraction:
https://data.nj.gov/api/views/w9se-dmra.json
```

For NES use `NAICS2022`, not the CBP example's `NAICS2017`; require metadata-confirmed totals for legal form and receipt size. For BDS use the time-series endpoint described by the source, not an invented year-specific endpoint. Actual integration caches confirm BLS monthly Morris unemployment-rate ID `LAUCN340270000000003` and employment ID `LAUCN340270000000005`. Resolve additional IDs from the catalog and preserve the unadjusted/adjusted distinction. The FRED annual Morris unemployment series ends in `A`, so it is not a substitute for monthly BLS data.

For DCA, page by a stable key/order and preserve extraction boundaries and versions. The [state's permit-derived view](https://data.nj.gov/d/vffm-2vwj) warns about incomplete coverage, recent unreviewed records, and potential retention limits. Verify these against the base feed and audited Reporter before promising a ten-year local microdata history. A snapshot today cannot recover purged records.

## Geographic and Time Rules

1. Start the county panel with all 21 NJ counties and 10-15 years of monthly LAUS where catalog coverage permits. Add bordering counties using pre-outcome commuting/adjacency rules, not by selecting the best backtest. Acquire QCEW history separately and join by county, sector, ownership and actual reference period.
2. Start the spatial panel with Morris and prespecified neighboring-county tracts, using LODES annual workplace measures and fixed-vintage ACS context. A target of roughly 150-300 usable tracts is a design aspiration; count actual stable, nonsuppressed areas after ingestion. Do not promise that many local tracts or independent observations.
