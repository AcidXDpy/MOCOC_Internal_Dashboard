# Statistical Validity and Release Gates

This file supplies the detailed per-method evaluation required by section 17 of [the technical design](technical-design.md). "Gate" means an evidence/release rule, not a request for permission. Existing integration calculations can remain visible with accurate experimental/context/scenario labels even when a stronger inferential claim is not supported. Future data are not counted as acquired and test fixtures are not economic evidence.

## Current Evidence Boundary

The inspected 2026-09-07 result bundle contains Morris County LAUS employment/unemployment-rate history January 2000-July 2026 (318 published monthly values and one missing month per series), 2018-2023 NJ county CBP comparisons (21 counties, 16 common sectors in the graph), and ACS 2024 Morris County tract household context (105 eligible tracts in current PCA/spatial outputs). These support current county labor and cross-sectional context/structure work. They do not create a wider multivariate county monthly panel, a tract time-series panel or a business survival cohort.

Current forecast limitations explicitly report that the selected state-space model underperforms seasonal naive on the final holdout, nominal intervals omit parameter/structural-break uncertainty, and 4-6 month forecasts lack matching-horizon validation. Therefore retain/show the baseline and do not claim superiority or calibrated full uncertainty. "Ready" in a machine-readable output means the computation can be displayed, not that it has won a scientific comparison.

The current-month county projection is univariate with lagged official data, not a mixed-frequency commercial nowcast. Current household PCA has mixed loadings and no valid uniformly favorable health orientation; its overall health score is null. Current spatial permutation tests condition on estimated incomes; independent MOE perturbations are sensitivity checks, not a survey-covariance model. Current graph edges represent co-specialization/similarity and current shock/benefit parameters are assumed. Survival and causal economic results remain null/gated despite tested reusable engines.

## Information-Time Evaluation Protocol

1. Define target, geography, reference period, horizon, transformation, source universe and first-release-versus-revised scoring target before splitting data.
2. Preserve actual raw vintages going forward. Record historical availability as verified/estimated/unknown; separate public availability from application retrieval. The current acquired files are latest-vintage histories, so their rolling validation is retrospective. If an assumed release lag is applied, label it pseudo-real-time.
3. Split a final chronological holdout once. Within earlier periods use expanding/rolling origins and inner tuning. All scalers, imputers, feature selection, graph/relatedness estimates, state fitting and reconciliation covariance must use only training-eligible information.
4. At each origin construct the actual or explicitly simulated information set. No annual interpolation, revised-target covariate or future weather/event data may be mislabeled as historically available. A future covariate forecast requires its own uncertainty or scenario.
5. Score the same target/horizon/observed cells for every model, retaining genuine gaps. Do not score an imputed missing target. Use observation masks and report n, origins, geography clusters and overlap in forecast horizons.
6. Report MAE/RMSE and proper probabilistic score/coverage/width by horizon and important groups. Do not infer statistically significant superiority from tiny dependent aggregate loss differences; use justified time/cluster uncertainty and economic importance.
7. Maintain a baseline champion/challenger record. If a complex model fails holdout or coverage, it remains an experimental comparator. Register prospective predictions and evaluate when later releases arrive; do not revise an archived prediction silently.

For interval $[l,u]$ with coverage $1-\alpha$, use interval score

$$
IS_\alpha(l,u;y)=(u-l)+\frac{2}{\alpha}(l-y)\mathbf1(y<l)
+\frac{2}{\alpha}(y-u)\mathbf1(y>u).
$$

This penalizes both unnecessarily wide bands and misses. Coverage alone rewards arbitrarily wide intervals. For discrete/event predictions use appropriate likelihood/Brier/quantile scoring; no MAPE on near-zero counts. Compare forecast calibration, scientific construct validation and causal identification separately.

## Model Card Required for Every Published Family

Each card includes target/estimand; support/population; observed and excluded sample; dates and available information; source/universe/NAICS/boundary versions; transformations; equations and parameter constraints; fitted-versus-proposed state; priors/tuning; baseline and split; metrics/interval meaning; convergence/fit diagnostics; spatial/temporal selection assumptions; known failures; subgroup and missingness limits; update/retraining policy; code/data/run versions; appropriate and prohibited interpretations.

A failed assumption should not be buried behind a generic "experimental" badge. State the practical implication: "household context only," "latest-vintage retrospective comparison," "no contemporaneous signals," "not validated beyond three months," "similarity edge, not transaction," or "no cohort outcome data." An informed user should be able to tell exactly what remains uncertain.
